# FE おぼえるノート

基本情報技術者試験（FE）の用語を日本語で覚える、静的な暗記ゲームです。4択クイズ、フラッシュカード、神経衰弱、60秒のタイムアタックを収録しています。外部ライブラリ・外部フォント・外部画像・インターネット接続・npmビルドは不要です。アプリからサーバへの通信は行いません。

## パソコンで開く

このフォルダの **index.html を Chrome / Edge / Firefox などのブラウザで開くだけ**です。ビルドもサーバも不要です。JSONを通信で取得する代わりに、同じ内容を埋め込んだ `fe_terms.js` を読み込むので、`file://` で動作します。

## iPhoneで開く

iPhoneの `file://` は環境によって動かないことがあります。同じWi-Fiに接続したパソコンで、このフォルダをカレントディレクトリにして次を実行します（Pythonが必要）。

```sh
python3 -m http.server 8000
```

Windowsでは `py -m http.server 8000` または `python -m http.server 8000` も利用できます。SafariでパソコンのIPアドレス、例えば `http://192.168.x.x:8000/` を開きます。接続できない場合は、パソコンのファイアウォールと同じWi-Fiにいるかを確認してください。終了はパソコン側で Ctrl+C です。

または、このフォルダをGitHub Pages等の静的ホスティングに配置し、HTTPSのURLをSafariで開きます。初めてページを取得する際には接続が必要です。Web公開したページのオフライン再読み込みは保証しません。

## 遊び方

- **4択クイズ**：既定20問（範囲が少なければ全件）。用語→意味／意味→用語をホームで切り替えられます。回答後に正解と意味を確認し、「次の問題へ」で進みます。ヒントは成績に影響しません。
- **フラッシュカード**：タップで表裏を切り替え、意味を確認してから「わかった」「もう一度」で評価します。前後のカードも確認でき、評価は1枚につき1回です。最大20枚。途中でも結果を表示できます。
- **神経衰弱**：最大8ペア＝16枚。用語と対応する意味をそろえます。違ったペアは1.5秒後に裏に戻ります。手数・ペア数・所要時間を表示します。
- **タイムアタック**：60秒間のクイズ。正解100点、連続正解で20点ずつ増えて最大200点。不正解の減点はありません。回答後の説明は0.85秒表示され、時計は進みます。自己ベストと最長連続正解を表示します。

分野・分類・出典のフィルタは全モードに適用します。誤りの選択肢も対象範囲内から選び、意味（逆向きでは用語）の重複を避け、同じ分類を優先します。異なる選択肢が4つに足りない場合は選択肢を減らします。苦手リストの単語だけを学ぶ場合は1択になります。

用語ごとに出題回数、正解数、連続正解、直近の結果、苦手度を保存します。不正解や「もう一度」で苦手度が上がり、連続正解で下がります。「わかった」は苦手度がゆっくり下がります。神経衰弱はペア成立で正解、違った場合は選んだ各用語に不正解を記録します。

出題は苦手度に応じた重み付き抽選です。未学習も混ぜ、苦手度が低い用語にも出題機会を残します。セッション内では重複させず、評価は次のセッション（タイムアタックでは次の一巡）に反映します。ホームの苦手リストはフィルタ対象から表示します。

ホームに戻ると進行中のゲームは終了します。回答済みの記録は残ります。タイムアタックはタブを離れても実時間で60秒が経過します。

## 用語の足し方

1. `fe_terms.json` の配列に、同じキー（`id`, `area`, `category`, `term`, `reading`, `meaning`, `hint`, `source`）のオブジェクトを1件追加します。`id` は重複させません。
2. このフォルダで `node sync_terms.js` を実行し、`fe_terms.js` を更新します。
3. `node validate.js` で確認します。

これらの作業だけNode.jsが必要です。ゲームを遊ぶだけなら不要です。`fe_terms.js` は自動生成用なので、直接編集せずJSONから同期してください。初期データは153件です。自己テストは「150件前後」を130〜170件として確認しています。将来大幅に増やす場合は、自己テストの件数範囲も調整してください。

## 記録の保存とリセット

記録とフィルタは **ブラウザのlocalStorageだけ**（キー：`fe-memorize-v1`）に保存します。端末・ブラウザ・URLを変えると記録は引き継がれません。元の環境の記録が消えるわけではありませんが、サイトデータ削除やプライベートモード終了等で消えることがあります。`file://` の保存の扱いはブラウザに依存します。保存できない環境では画面に案内し、その画面を開いている間だけ記録します。

ホームの「記録と復習のしくみ」内のリセットを押し、確認ダイアログで承認すると、このアプリの記録・自己ベスト・設定を削除します。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | 入口・日本語ページ |
| `styles.css` | モバイル対応の表示 |
| `app.js` | ゲーム画面・操作・保存 |
| `game-core.js` | 抽選・選択肢・苦手度計算 |
| `fe_terms.json` | 元の完成済み用語データ |
| `fe_terms.js` | JSONと同一内容のブラウザ用データ |
| `sync_terms.js` | Node.jsでデータを同期 |
| `validate.js` | データ・参照・外部通信不使用・ゲーム計算の自己テスト |
| `app-smoke.js` | 画面操作・保存・タイマーの連携テスト（validate.jsから実行） |

## 自己テスト

```sh
node validate.js
```

全項目「合格」、終了コード0を確認します。データは書き換えず、ブラウザ用データとの全内容一致も検証します。
